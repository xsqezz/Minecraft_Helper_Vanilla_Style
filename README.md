# BratanSgg Vanilla Button

Mod Fabric client-side dla Minecrafta 1.21.11. W lewym górnym rogu ekranu pokazuje przyciski z nickami wszystkich innych graczy w promieniu 100 bloków. Każdy gracz ma osobny przycisk, a lista układa się pionowo. Gdy w zasięgu nikogo nie ma, wyświetla się przycisk „Vanilla”.

Lista obejmuje także graczy za ścianą, niewidzialnych i poza polem widzenia, jeśli znajdują się w promieniu 100 bloków i są dostępni klientowi.

## Obsługa

- Naciśnij V, aby przełączyć kolor i stan przycisków.
- Naciśnij Prawy Shift, aby odblokować lub ponownie zablokować kursor.
- Gdy kursor jest odblokowany, kliknij dowolny przycisk, aby zmienić stan. Po kliknięciu kursor zablokuje się ponownie.

Przełącznik zmienia wyłącznie stan i kolor przycisków; nie zmienia mechaniki świata.

## Instalacja

Wymaga Minecrafta 1.21.11, Fabric Loader oraz Fabric API. Włóż plik bratansgg-1.0.0.jar do folderu mods.

Gotowy plik JAR jest dodawany jako artefakt w GitHub Actions po zbudowaniu projektu.
